# RAG contract v1

The local Index is application-configured, constructed without database I/O and explicitly initialized in a separate SQLite file. Operations own/close their connections. There is no live database connection across a provider await. This is a local storage experiment; PostgreSQL remains the academy deployment database. No automatic migration, source URL fetch, provider account or learner-upload execution occurs.

`publish`: revalidate a complete Record and its document/vector identity using the prior retrieval window/vector contract (width=96/overlap=24). Use one BEGIN IMMEDIATE transaction to check the current state, replace a whole scoped document and increment its epoch. The key is (tenant,document). A newer revision replaces text, vectors, ACL, activity and metadata together. Exact same-revision replay returns False without an epoch change. Old/conflicting revisions raise ValueError. Tombstones have document=None and no vectors, retain their revision, and prevent old data from returning after reopen. A newer revision may explicitly restore a document. At most 16 identities, including tombstones; at most 64 stored chunks. Any validation/cap/SQL failure rolls back the whole publication. No general ingestion/reindex migration or distributed transaction guarantee is supplied.

`prepare`: revalidate Principal/Query/Filters/Policy and read one consistent epoch/record snapshot. Compose prior exact cosine retrieval with configured candidate k (1..10) and access/activity/topic/document/minimum-score filters BEFORE evidence reaches the provider. Then require all application-owned ASCII task terms (1..3 unique lowercase words, 2..32 characters) in each candidate chunk's token set. This intentionally limited gate cannot infer semantic support and is not chosen by document instructions. Rerank surviving candidates by descending ASCII set Jaccard against the question, descending cosine, then complete Key. Choose at most 1..3 whole passages; serialize evidence IDs, full source keys, offsets, digest and exact text into an explicit UTF-8 evidence-list budget (16..4096 bytes). Skip a passage that does not fit; never cut its text. IDs e0/e1/e2 are local to this exact Bundle. Record omitted count and source epoch. The full provider envelope has a separate context check.

`answer`: refresh an application-supplied synchronous authority callback before use. Its exact Principal must equal the bundle's snapshot. Reprepare against current index state and compare the whole bundle; any mismatch abstains before a call. Missing evidence also abstains with zero attempts/charge. The callback supplies trusted application permission state, never model/query/document-selected roles.

Compose the prior public ModelConfig, Limits, Request and borrowed Adapter/Provider contracts. Build a distinct canonical `rag-quotes-v1` envelope with configured provider/dialect/model/prompt identity, application instructions, question and a separately labelled untrusted evidence list. The earlier triage output decoder/schema is deliberately not reused for RAG. Input units are the FULL serialized UTF-8 byte count plus configured output reserve, explicitly fixture units rather than real tokens. Check context and reserve fictional integer cost before the one possible call. No retry or second call. A cooperative timeout awaits cancellation cleanup; external CancelledError propagates. Unknown usage keeps the reservation; no durable account ledger is supplied.

Raw response is exact bytes <=16384, strict UTF-8 duplicate-free/non-finite-free JSON with exactly model/schema/status/claims/usage. Check configured identities and complete/refused/incomplete. Usage is exact nonnegative int (no bool) within input/output bounds; valid known usage settles fictional cost. Refusal/incomplete must have claims=null and returns no answer. Complete claims are a nonempty list of at most two exact {evidence,quote} objects. References must name distinct selected IDs, and each quote must EQUAL its selected whole source span. No paraphrase, arbitrary repair, generated URL, unselected/private citation or extra command is accepted. Valid usage can still accompany unsupported claims; unsupported shape/identity/usage retains the unknown full reserve until metering is valid. Never return raw failure strings.

After a valid proposal, refresh authority again and compare it with the pre-call principal. Reprepare/current epoch/evidence must still match. Resolve citations against current allowed active document revision/offset/digest/text; a source update, ACL change, deletion or permission change during generation discards all text/citations. Build visible text only from validated exact source excerpts. This verifies provenance/quoting at that observation point, not truth or whether an excerpt answers the question. Any index epoch change conservatively invalidates a bundle, even an unrelated update. Later changes require fresh citation resolution; there is no safe answer-cache/reuse guarantee. Source metadata and authority callback correctness remain trusted application assumptions.

`resolve`: no URL fetch. Return an exact source span only when the full current key, text, character offsets and UTF-8 digest match and the current application principal can read its active document. Otherwise return None; never fall back to an older revision. This is required when revisiting old citations, not just on initial answer creation.

The 70 public cases and guarded demo use original fixed documents, hand-supplied two-dimensional vectors and controlled transports. They verify local transactions/reopen, scope, explicit gating/reranking/budgets, citations, abstention, refreshed permissions/source state and cooperative cancellation. They do not evaluate a real model, retrieval on future data, semantic entailment, hostile prompt resistance, production SQLite/PostgreSQL operations or learner originality. Installed reports and an independent regression/design note receive labelled manual review; objective tests, reading and self-report stay separate from mastery.

Primary reading: [original RAG paper](https://arxiv.org/abs/2005.11401), [Python sqlite3 transaction control](https://docs.python.org/3.13/library/sqlite3.html#transaction-control), [asyncio timeout](https://docs.python.org/3.13/library/asyncio-task.html#asyncio.timeout).
