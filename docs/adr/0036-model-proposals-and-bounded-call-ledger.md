# ADR 0036: Offline model proposals and a bounded call ledger

Date: 2026-10-08
Status: accepted

## Context

The fixed fifth step-six milestone requires deterministic provider adapters, validated output/refusals/timeouts and explicit context/cost/step budgets. The existing introduction distinguishes proposal shape, truth and permission, but there is no connected installed implementation. Live provider access/prices and model accuracy cannot be inferred from local success. The academy must not execute learner code or use a model as grading/authorization authority.

## Decision

Publish six simple lessons and a separate Model call contracts skill with complete private guided/recall, accessible diagrams and glossary. Serve an exact fourteen-file starter with three unfinished functions, 84 public cases and four manual criteria. Keep maintained operations outside the download. The independently installed package uses the standard library, not an academy runtime/provider dependency.

A configured Adapter borrows an async Transport. Two invented message/completion wire formats are supported; they are not named-provider emulations. Requests snapshot configured provider/model/prompt/schema identities and canonical complete UTF-8 envelopes, keeping user text separate from application instructions. Preflight validates every bounded prompt before any call. Complete serialized byte count plus output reserve is an explicit fixture context rule, not a real tokenizer or universally conservative estimate.

Normalize strict bounded UTF-8 duplicate-free JSON, exact identity/usage/variants and triage fields. Only complete valid output creates a frozen Decision. Refusal/incomplete text is discarded and never parsed into actions. No coercion, arbitrary repair, generated authorization or truth assertion is introduced. Provider-reported usage is checked only against fixture bounds, not independently audited.

Before each actual attempt, reserve full supported input/output fictional integer credits. Admission that cannot fit makes no call. Fully validated known usage settles and releases unused reserve. Refused/incomplete replies settle known usage but stop. Timeout/provider error/invalid response retains the full reservation and stops; missing usage is never assumed free. Attempts are step-bounded; no automatic retry is supplied.

Use one monotonic cooperative deadline after preflight across provider waits. Await fixture cancellation cleanup; external CancelledError propagates. Borrowed transports remain reusable. Blocking or cancellation-suppressing work/slow cleanup cannot be forcibly stopped, and synchronous preflight/parsing or transport buffering are not hard interrupted. A new run has a new local ledger; external cancellation produces no durable report. Durable distributed quota/billing/reconciliation and remote rollback guarantees are outside this unit.

Installed JSON pins versions and eleven finite demo cases without raw prompts/refusal reasons/exceptions. Public tests and request spies are trusted local fixtures. Learners submit actual installed artifacts plus an original regression/design note for labelled self/human review; reported evidence never automatically awards mastery.

## Verification and consequences

Maintained source and fresh outside-source archive/wheel installation pass all 84 public cases without skips and strict type/import/resource-marker checks. Both wire formats, exact context/reservation boundaries, usage uncertainty, attempt limits and an actual waiting-call timeout/external cancellation cleanup are verified. Focused academy/browser checks verify private learning keys, navigation, exact download, account-owned/fixed review artifacts and responsive layout. Existing learner rows, exam banks, old skill denominators and prior practical/API lab sources remain unchanged.

No model inference, network/paid request, semantic quality, provider capability/current pricing/real billing or authorization proof is claimed. The fifth fixed milestone is complete as finite application teaching/practice. Four fixed AI milestones remain; Embeddings and retrieval is the exact next action, while step 6 and later whole-academy operations remain open.
