# ADR 0035: Composed Python practical review with separate manual originality

Date: 2026-10-08
Status: accepted

## Context

Step 6 has a fixed fourth milestone: connect the published Python/backend work into a practical artifact, profile a stated workload and preserve earlier callers. Earlier units and the advanced knowledge evaluation cannot establish expert competence. The academy already stores fixed manual submissions/rubrics/revisions; it must never run uploaded packages in its API.

## Decision

Publish five simple lessons and a separate skill with all guidance/diagram/glossary/recall layers. Add an allowlisted eighteen-file starter with three unfinished functions, 50 finite public cases and four grouped manual criteria covering the seven advanced dimensions in PYTHON_LEVELS.md. Keep the completed implementation under reference/ and outside the ZIP.

Compose eight selected version-0.1.0 local packages in a clean outside-source installation: ingestion, feed objects, typed transforms, resource scopes, bounded offload, measured cache, original ingestion service and practical review. A generated disposable service_002 schema deliberately exercises supported original callers. Later delivery_004/query/API packages and source code are not downgraded or modified. Strict service values retain 0..1000000; the earlier report domain retains 0..60000 and refuses incompatible values, including obsolete revisions. Copy frozen values, check complete-key conflicts, select latest revisions and preserve zero.

Collect four actual loopback async pages after fixture writes stop; responses close on failures/cancellation and the client stays borrowed. Reuse owned resource/context and bounded thread/spawn workers with worker-local files and joined cleanup. No global multi-page snapshot, arbitrary hostile memory bound or hard end-to-end deadline is claimed.

Measure a stated synthetic reporting component after collection: 32 latest items, 152 hot/cold requests, equivalent snapshots/fingerprints and baseline/cached 152/32 computations with 120 hits. A 32-id cyclic counterexample gives 64/64 and zero hits. Record three wall and process-CPU intervals, separate cProfile text/actual fingerprint call counts and separate tracemalloc retained/peak/released observations. Refuse an already-owned tracer. No faster-time, smaller-allocation, RSS, production-demand or whole-service-throughput gate is introduced.

Require an independently authored bounded JSON case with predicted outputs/counts, a separate original regression against a proposed wrong change and a decision note. The local data-only helper checks finite expectations, never imports Python or detects originality. A maintainer example and browser submission fixture are explicitly labelled. In-app saved drafts, fixed submissions/rubrics, self/human feedback and revisions preserve history. Originality and design quality require manual judgment; no practical mastery is automatically awarded.

## Verification and consequences

Eight maintained source archives/wheels pass fresh installation/import/type checks. All 50 public cases pass with actual PostgreSQL 17.11 and no skips; the installed demo records HTTP permissions/duplicates/conflict rollback, preserved source facts/head, actual profiling/thread/spawn results and owned cleanup. Focused academy and browser checks verify the learning path, exact ZIP, private answers, account ownership and frozen artifact revisions. Existing learner state, exams and prior source contracts remain unchanged.

The fourth fixed milestone is complete as a learning/review workflow; no learner originality or certification is asserted. Five applied AI milestones and broader expert/security/operations work remain. One continuation must implement Model contracts next, without starting step 7 or expanding this completed milestone.
